## Ghost Controller v0.3.3 — cleaner UI, part 2

### Changed
- Removed remaining helper text: the Connection Lost / Video signal lost
  sub-lines, the Kill Switch "Double-click" caption, the Video Source panel's
  status line and per-mode descriptions, parameter-edit key hints and the
  "No serial devices found" note. Errors and live status are unchanged.

### Downloads
- Windows 10/11: `Ghost_Controller-Setup-x86_64.exe`
- Linux x86_64 / ARM64: `Ghost_Controller-*.AppImage`

### How to update
Linux / Raspberry Pi:

    curl -fsSL https://raw.githubusercontent.com/Sai-Tolle/Ghost-Controller-/main/install.sh | bash
