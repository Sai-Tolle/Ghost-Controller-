## Ghost Controller v0.2.0 — redesigned UI, light theme, Pi link fixes

### New look
- Apple-style interface: Inter typeface, system colours, translucent panels,
  real vector icons, segmented controls and macOS-style menus throughout.
- **Light theme.** Switch under the app menu (Ghost Controller ▾) →
  *Appearance*: Dark, Light or Auto (follows the OS). The choice is remembered.
- New compass **heading tape** and a cleaner **roll scale** at the top of the HUD;
  pitch ladder fades at the edges and dashes below the horizon.
- Less clutter: helper/explainer captions removed; errors are shown in red.

### Connecting (Raspberry Pi testers, please update)
- **Auto** now tries every USB serial device *and* the Pi GPIO UART
  (`/dev/serial0`) at **57600 and 115200** baud, then listens for UDP.
  Before, it tried only the first USB device at 115200, so SiK/RFD telemetry
  radios (57600) and the GPIO UART never connected in Auto.
- The UDP fallback now listens on `0.0.0.0:14550` (was loopback only), so
  Wi-Fi telemetry bridges sending to the Pi's IP are heard.
- Plain-language errors in the Connection dialog: permission denied
  (dialout group), port busy, no heartbeat (baud / wiring), UDP port in use.
- The serial-port list offers `/dev/serial0` on the Pi.
- The installer prints the `dialout` command with your username filled in,
  and skips it when you are already in the group.
- New troubleshooting table in `docs/TESTERS.md`.
