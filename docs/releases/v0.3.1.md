## Ghost Controller v0.3.1 — Windows installer

Everything in [v0.3.0](https://github.com/Sai-Tolle/Ghost-Controller-/releases/tag/v0.3.0)
(use any video link: Radio System presets, auto-detected UDP video, Stream
URL, USB/HDMI capture), now with the **Windows installer** attached.

### Fixed
- **Stream URL** with `udp://`: a fast sender no longer stops the stream with
  an I/O error while it is starting.

### Downloads
- Windows 10/11: `Ghost_Controller-Setup-x86_64.exe` (no admin rights needed;
  see [TESTERS.md](https://github.com/Sai-Tolle/Ghost-Controller-/blob/main/docs/TESTERS.md#w-windows-10--11-x86_64))
- Linux x86_64 / ARM64: `Ghost_Controller-*.AppImage`

### How to update
Linux / Raspberry Pi:

    curl -fsSL https://raw.githubusercontent.com/Sai-Tolle/Ghost-Controller-/main/install.sh | bash

Windows: download and run the newest `Ghost_Controller-Setup-x86_64.exe`.
Details: [docs/UPDATING.md](https://github.com/Sai-Tolle/Ghost-Controller-/blob/main/docs/UPDATING.md)
