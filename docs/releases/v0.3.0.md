## Ghost Controller v0.3.0 — any video link, and Windows

### New
- **Use the video link you already have.** Video Source → **Radio System**:
  one tap sets video *and* telemetry for
  - Analog 5.8 GHz receiver + USB capture dongle (SiK / RFD900 telemetry auto-detected)
  - Anything with HDMI out (HDZero, Walksnail VRX, RC HDMI out) + capture card
  - SIYI HM30 / MK15 / A8 mini / ZR10, CubePilot Herelink, Skydroid H12/H16/H30/G16
  - OpenIPC (H.265), WFB-ng / OpenHD (H.264)
  - IP radios (Doodle Labs, Silvus, Microhard)
  - **Any other system** — see below

  If a vehicle is connected, only the video changes; the telemetry link is
  left alone.
- **Any video system works**, named or not:
  - *Automatic* now detects H.264 RTP, H.265 RTP or MPEG-TS on UDP 5600 by itself.
  - *Stream URL* plays any network stream: rtsp, rtmp, srt, udp, rtp, http/HLS.
  - *USB / HDMI Capture* lists capture devices by name and recovers when a
    dongle is unplugged and plugged back in.
  - RTP H.264, RTP H.265 and MPEG-TS can also be pinned to any UDP port.
- **Windows installer** — `Ghost_Controller-Setup-x86_64.exe` (Windows 10/11,
  no admin rights needed). See [TESTERS.md](https://github.com/Sai-Tolle/Ghost-Controller-/blob/main/docs/TESTERS.md#w-windows-10--11-x86_64).

### Changed
- The "No vehicle link" screen no longer shows the helper text under the
  heading. Link details stay in Connection Settings.
- UDP "Send To" links now send a GCS heartbeat while waiting, so radios that
  wait to hear from the GCS first (SIYI ground units) answer.

### How to update
Linux / Raspberry Pi:

    curl -fsSL https://raw.githubusercontent.com/Sai-Tolle/Ghost-Controller-/main/install.sh | bash

Windows: download and run the newest `Ghost_Controller-Setup-x86_64.exe` from
the release page. Details: [docs/UPDATING.md](https://github.com/Sai-Tolle/Ghost-Controller-/blob/main/docs/UPDATING.md)
