## Ghost Controller v0.2.2 — fixes the app closing after about a minute

**Please update.** v0.2.0 and v0.2.1 can close on their own about 1–3
minutes after launch.

### Fixed
- **App closing by itself.** The v0.2.0/v0.2.1 builds were packaged with
  Qt/PySide6 6.12.0, which corrupts memory in this app and makes it abort
  (`free(): invalid pointer`) about a minute after starting, with or without a
  vehicle connected. The build now uses PySide6 6.11.2, which ran
  multi-minute soak tests against PX4 SITL without a problem. Dependency
  versions are now pinned so a new upstream release can't slip into a build
  untested.

### New
- **Crash log.** If the app ever closes unexpectedly, a stack trace is saved to
  `~/.cache/ghost-controller/crash.log` — please attach it to your report.

### How to update
Re-run the installer (or see
[docs/UPDATING.md](https://github.com/Sai-Tolle/Ghost-Controller-/blob/main/docs/UPDATING.md)):

    curl -fsSL https://raw.githubusercontent.com/Sai-Tolle/Ghost-Controller-/main/install.sh | bash
